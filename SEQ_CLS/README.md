<h1>情感分析任务</h1>
<h2>题目描述：</h2>
<p>在数字化时代，社交媒体和在线评论平台已成为公众获取信息和表达意见的重要渠道。评论中蕴含的情感色彩对读者的认知和情绪有着显著的影响。评论情感分析旨在自动识别文本中的情感倾向，如积极、消极或中性。本赛题要求参赛者使用适当的微调技术对给定的大语言模型（QwenQwen-1.8B）进行微调，准确识别评论文本的情感倾向(消极:0、中性:1、积极:2）。</p>
<h2>数据集描述: </h2>
<p>训练集（文件夹”任务一train“中train.csv）包含5000条带有情感标签(消极：0、中性：1、积极：2）的文本数据，用于模型的训练；测试集(文件夹”任务一test“中test.csv)包含1500条不带标签的文本数据，用于模型的推理。</p>
<h2>任务描述：</h2>
<ol>
<li>
数据预处理
<ol>
<li>参赛者需要对给定的数据集进行预处理并划分训练集和验证集,保存处理后的数据集以备后续使用。</li>
</ol>
</li>
<li>
微调算法选择与实现
<ol>
<li>选择并实现一种高效的微调算法，如LoRA。</li>
<li>对大语言模型进行微调。</li>
</ol>
</li>
<li>
模型推理与评估
<ol>
<li>使用微调后的模型在测试集上进行推理，考生应提交测试数据集的结果文件。</li>
<li>按《提交说明》的要求提交结果文件“result1.json”</li>
</ol>
</li>
</ol>
